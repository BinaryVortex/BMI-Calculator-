# BMI Calculator

A simple web-based BMI (Body Mass Index) calculator built using HTML, CSS, and JavaScript. This tool allows users to calculate their BMI by entering their weight in kilograms and height in centimeters.

## Features

- **User-friendly Interface**: Clean and responsive design for easy input and output.
- **BMI Calculation**: Automatically computes BMI based on provided weight and height.
- **Category Classification**: Displays BMI value along with health category (Underweight, Normal, Overweight, Obese).
- **Visual Scale**: Includes a color-coded scale to visually represent BMI categories.
- **Reset Functionality**: Easily clear inputs and results with the reset button.

## How to Use

1. Open `index.html` in your web browser.
2. Enter your weight in kilograms.
3. Enter your height in centimeters.
4. Click the "Submit" button to calculate your BMI.
5. View your BMI value and category in the output section.
6. Use the "Reset" button to clear the form and start over.

## Technologies Used

- **HTML**: Structure of the web page.
- **CSS**: Styling and layout.
- **JavaScript**: Logic for BMI calculation and dynamic updates.
